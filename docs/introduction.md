`react-native-watch-connectivity` lets a React Native iPhone app communicate with its companion Apple Watch app.

**Note:** this library does not let you write a watch app in React Native. Your watch app must be written in Swift or Objective-C.

Features:
- Interactive messaging and background transfers: user info, application context and files.
- Complication updates.
- Watch state: reachability, pairing and watch app installation.
- Typed errors with stable codes.
- Safe to import on iPad, Android and the web, where every call is a no-op.

Upgrading from 2.x? Read [Migrating from 2.x to 3.0](./migrating-to-3.md).
